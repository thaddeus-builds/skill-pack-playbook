The owner asked (2026-11-02) for a review of the design: improve it, refactor it, make it best practice, in stages. Each stage ends with every skill pack still installable and its suite green, and with this page and [ROADMAP.md](../../ROADMAP.md) saying what is next. The host in use is Zylos (OpenMax); other hosts are not the focus.

This page holds the findings and the stages. The ROADMAP holds one row per stage and points here. A stage is one or more sessions; a session takes the first stage that is not done.

### Stage 2: every skill pack green on its own main (done 2026-11-03)

Every pack's own suite was run on its main in a Linux cloud session, and green means green on Python 3.12 (the owner's decision of 2026-11-02, R18). Each red one was fixed at its cause, in its own pack, under its own rules:

| Pack | What was wrong | Pull request |
| --- | --- | --- |
| proofcut | `film render`, `film spec` and `compute film-spec --json` gave warnings without `warning_codes` (a `--json` contract defect, seen only on a machine without the client's fonts) | proofcut #3 |
| amazon-ppc | its own Zylos adapter counted a zombie job as alive, so a finished job blocked its own re-run on a host whose init reaps late (the playbook's adapter had the rule; R3 kept it out); its clean run could not reach npm behind a TLS proxy | amazon-ppc #62 |
| sdr | the budget test's busy loop met a CPython 3.13 bug (an exception a signal handler raises escapes every `try` of that frame); on 3.12 a `From` with two angle addresses was read as the first one, because 3.12's header parser drops the rest where 3.13 refuses the line | sdr #73, sdr #74 |
| adcut | its usage test wanted 3.13's argparse wording; 3.12 refuses a stray word itself (same coded refusal) | adcut #278 |

On 3.12 every suite ends green, with two notes. sdr: the speed checks of its mail reader take 1.01 to 1.22 s against a 1.0 s bound (half its 2 s budget) on a 4-core VM; making the reader faster touches its stop cues, so it is the pack's call (sdr #72). product-image-to-video: 205 passed once uv's cache holds its wheels, but with an empty cache 109 checks are skipped and still counted as passed (product-image-to-video #15, the pack's own fix). adcut needs the Noto CJK fonts installed (its runner says so); with them, 337 of 337 files pass.

Found on the way and kept for later stages: Python floats (F9, the pin in Stage 3, X29); a shallow clone of the playbook makes `fleet.py status` unable to tell an old copy from an edited one (it says so; unshallow first); a clean environment needs the proxy's CA for both Python (`SSL_CERT_FILE`) and Node (`NODE_EXTRA_CA_CERTS`).

- `python3 scaffold/add_zylos.py --skill-pack DIR --port N` on ad-copy, asset-handoff, google-ads, meta-ads, proofcut and product-image-to-video, with ports kept apart on one host; one pull request per pack.

- Each pack's suite runs `node zylos/lib.js check`.
- One naming and one port table for the fleet: the linked commands are named three ways today (`openmax-seo`, `coco-sdr`, `adcut-skill-pack`), and the console ports (seo 8766, adcut 8771, sdr 18768) sit beside the range a client hub's console takes (8770 and up). - One Python (R18, X29): the same pull request gives the pack a root `.python-version` of `3.12`, so `uv run` uses the 3.12 the adapter installs instead of the newest it finds; the adapter's `check` refuses a pack whose `.python-version` and `runtime.python` disagree; the kit's test runner names the interpreter it ran on.
- amazon-ppc keeps its own adapter (R3); cloud-gpu is a library and gets none.

Done when: `node zylos/lib.js check` passes on 9 packs at the current adapter (0.6.2 or later), and an install on one real Zylos host is reported by its host agent for at least one pack that had no adapter.

# Research: what was looked up, and what came of it (the playbook)

Before researching a question, read this index: if it is here, read the file, check its date and what it could not read, and extend it rather than start over. A new piece of research is a file in this folder and a row below (question, date, answer in one line, where it is used). Evidence stays here; what was decided is in `ROADMAP.md` (the R rows) and `docs/design/`.

Every file says `Researched YYYY-MM-DD`, ends with its kinds of claim and where it is used, and tags each claim **[documented]** (the platform's own words), **[vendor]** (a tool vendor or practitioner), **[academic]**, **[ours]** (measured on a client's data or our own repositories) or **[inference]** (the researcher's reasoning, not a source). A page that could not be read is said so: "unconfirmed" means looked for and not found.

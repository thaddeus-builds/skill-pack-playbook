# Research: what was looked up, and what came of it ({{name}})

Before researching a question, read this index: if it is here, read the file, check its date and what it could not read, and extend it rather than start over. A new piece of research is a file in this folder and a row below (question, date, answer in one line, where it is used). Evidence stays here; what the skill pack decided is in `docs/ROADMAP.md` (the R rows) and `ssot/`.

Every file says `Researched YYYY-MM-DD`, ends with its kinds of claim and where it is used, and tags each claim **[documented]** (the platform's own words), **[vendor]** (a tool vendor or practitioner), **[academic]**, **[ours]** (measured on a client's data) or **[inference]** (the researcher's reasoning, not a source). A page that could not be read is said so: "unconfirmed" means looked for and not found. `tests/test_ssot.py` fails on a file with no row below and a row with no file.
